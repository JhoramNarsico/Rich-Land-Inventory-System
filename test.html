Master Test Plan

System / Project Rich Land Integrated Operations System (RL-IOS)
Assigned Testers Jhoram Narsico & Joseph Alberto
Date Designed April 27, 2026
Date Conducted May 14, 2026

1. Objective

To verify that the RL-IOS seamlessly integrates core inventory tracking, point-of-sale checkouts, financial ledger calculations, and custom hydraulic Statement of Work (SOW) generation while enforcing strict role-based access control and accurate data caching.

2. Test Scope

  • Included: Core Catalog CRUD operations, Real-time virtual Point of Sale (POS) cart calculations, Customer balance and ledger updates, Hydraulic SOW data capturing, Purchase Order receiving, Expense categorization, and API Endpoint security.
  • Excluded: Multi-branch and multi-warehouse tracking, Integrated Payment Gateway (Stripe/PayPal handshakes), Public e-commerce storefronts, Complex double-entry accounting tax rules, and Employee timeclocks/payroll calculations.

3. Test Environment

  • Operating System: Windows (Client/Testing) / Linux (Production Deployment)
  • Tools Used: Web Browser (Chrome/Edge), Terminal, Swagger UI
  • Network Setup: Cloud deployment accessed via internet (HTTPS), routed through Render Edge Load Balancer & CDN.
